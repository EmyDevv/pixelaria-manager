# 💜 Pixelaria Manager

Sistema de gerenciamento desenvolvido para a **Pixelaria**, uma pequena loja de acessórios artesanais.

## 📌 Sobre o projeto

O Pixelaria Manager é um projeto pessoal desenvolvido com o objetivo de facilitar a organização e o gerenciamento de uma pequena loja artesanal.

A aplicação está sendo construída para auxiliar no controle de pedidos, produtos e informações financeiras do negócio.

Além de atender a uma necessidade real, o projeto faz parte do meu processo de aprendizado em Análise e Desenvolvimento de Sistemas (ADS) e da construção do meu portfólio na área de tecnologia.

## 🎯 Objetivos

- Desenvolver uma aplicação para gerenciamento de pequenos negócios.
- Praticar conceitos de desenvolvimento web.
- Aplicar conhecimentos de programação em um projeto real.
- Evoluir gradualmente a aplicação, incorporando novas funcionalidades e tecnologias.

## 🛠️ Tecnologias utilizadas

Atualmente, o projeto utiliza:

- HTML5
- CSS3
- JavaScript

## ⚙️ Funcionalidades

Funcionalidades em desenvolvimento:


3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
